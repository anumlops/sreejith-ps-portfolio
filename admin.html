Getting Started — One-Time Token Setup

  1. Go to GitHub → Settings → Developer settings → Personal access tokens → Tokens (classic)
  2. Click Generate new token (classic)
  3. Give it a name like "Site Editor" and set expiration as you prefer
  4. Under Scope, check only repo (full control of private repositories)
  5. Click Generate token and copy it — GitHub will only show it once
  6. Paste the token into the "GitHub Token" field above
  7. Ensure Owner and Repo fields match your GitHub (default: anumlops / sreejith-ps-portfolio)
  8. Click "Save & Publish" — Vercel auto-deploys within ~30-60 seconds

Your token stays in browser memory only. Refreshing the page clears it — paste it again on your next editing session.

Adding Photos

  1. Create an /images folder in your repo (via GitHub web UI or GitHub Desktop)
  2. Upload your photo files there
  3. Reference them in the Gallery fields as images/your-photo-name.jpg
  4. Update the hero landscape photo and portrait photo paths in style.css directly (search for REPLACE: comments)
